
# DavanteDent

Trabajo de enfoque del módulo Desarrollo Web en Entorno Cliente.
Aplicación para gestionar citas de la clínica dental DavanteDent.

## Qué hace
- Añadir citas con validación
- Ver citas guardadas en cookies
- Modificar y eliminar citas
- Comprobar que no se solapen las citas
